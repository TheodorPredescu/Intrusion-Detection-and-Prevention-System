# Industrial Network Security System

[Documentation](./document/licenta/lucrare_licenta.pdf)

## Abstract

The presented thesis lays the foundation for a security model designed for industrial control systems.

The proposed solution consists of two components intended to run on industrial equipment: a server component and a desktop application for general system control. The system uses access control rules based on well-defined policies configured and managed by the system administrator.

Through its modular nature and its ability to collect inspection information, the solution provides the necessary flexibility to integrate additional traffic inspection methods in the future, such as anomaly-based and signature-based detection methods.

The application focuses on the remote configuration and inspection of filtering settings, monitoring intrusion events occurring at the level of the protected components, and providing graphical visualization of communication members within the local network.

Although the filtering capabilities and the overall reliability of the proposed implementation may not be sufficient for large-scale industrial environments, the concepts and logical components presented in this work can contribute to the development of a more comprehensive solution capable of addressing modern security requirements and protecting against intrusions.
